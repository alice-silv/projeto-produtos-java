# Projeto Produtos - Java

Continuidade de projeto desenvolvido durante a capacitação, com foco na aplicação de conceitos iniciais de Java.

## Objetivo
Aplicar conceitos básicos de programação orientada a objetos na manipulação de produtos.

## Desenvolvimento
Este projeto representa meu primeiro contato prático com Java.
Durante a atividade, busquei compreender a estrutura básica de classes, atributos e métodos, realizando melhorias simples para consolidar o aprendizado.

## Melhorias realizadas
- Organização da classe Produtos
- Implementação de validação para preço negativo
- Ajustes na estrutura do código

## Aprendizados
Experiência inicial com programação orientada a objetos, encapsulamento e validação de dados.
